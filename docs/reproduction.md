# Reproduction Guide

All commands below run from the repository root. Generated output is written
to `build/reproduction/` and is not tracked.

## Stable Commands

```bash
make test-python
make test-julia
make verify-manifest
make verify
make reproduce
```

`make reproduce-full` runs the complete cutoff-qualified Python BB validation
and is intentionally not a per-push CI target. Both Python reproduction
targets execute from a copied snapshot under `build/reproduction/python/`, so
generated results never modify tracked notebooks or source files.

## 6.6.6 And 4.8.8 Color Codes

The worked Sage notebooks are:

- `python/results/decoupling/666_color_code.ipynb`
- `python/results/decoupling/488_color_code.ipynb`

Both notebooks consume canonical JSON generated by their matching scripts.
Run the paper-specified superlattice validations with:

```bash
rm -rf build/reproduction/python
mkdir -p build/reproduction/python
cp -R python/decoder_core python/decoupling python/results python/scripts \
  build/reproduction/python/
cd build/reproduction/python
sage scripts/decoupling/reproduce_666_color_code.sage
sage scripts/decoupling/reproduce_488_color_code.sage
```

The Julia 6.6.6 example is:

```bash
julia --project=julia/ToricBuilder \
  julia/ToricBuilder/example/scripts/color_code.jl
```

## BB Validation

The Python entrypoint is
`python/scripts/decoupling/reproduce_bb_codes.sage`. It contains the complete
shared 59-row catalog and uses stable identifiers. A one-row smoke run is:

```bash
cd build/reproduction/python
sage scripts/decoupling/reproduce_bb_codes.sage \
  --rows benchmark-01 \
  --output-json ../python-bb-benchmark-01.json \
  --output-csv ../python-bb-benchmark-01.csv \
  --output-markdown ../python-bb-benchmark-01.md \
  --checkpoint-json ../python-bb-benchmark-01.checkpoint.json
```

The default full run validates every row at or below the paper's
`benchmark-19` runtime cutoff. It supports atomic checkpoints, resume,
retries, row timeouts, and explicit selectors; only validated complete runs
publish their JSON, CSV, and Markdown outputs.

## Python Decoder Benchmark

The paper-family decoder comparison entrypoint is
`python/scripts/unitary_decouple_based_decoder/benchmark_paper_bb_family.sage`.
It compares the unitary-decouple-based decoder with BP-OSD using identical

```bash
cd python

  --smoke
```

## BB Decoupling Tables

The two complete Julia tables are:

- `julia/ToricBuilder/results/bb_code_decoupling_results.md`: 54 rows, of
  which 31 have complete decoupling results;
- `julia/ToricBuilder/results/additional_bb_code_decoupling_results.md`: 99
  rows, of which 29 have complete decoupling results.

They are generated by `julia/ToricBuilder/example/scripts/decouple_bbcodes.jl`
and `julia/ToricBuilder/example/scripts/decouple_additional_bb_codes.jl`,
respectively.

The additional set cites each source family in its labels and generating
script. The doubled `[[288,12,18]]` Gross-code case is derived from the
`[[144,12,12]]` Gross code of Bravyi et al., *Nature* 627, 778-782 (2024),
[DOI 10.1038/s41586-024-07107-7](https://doi.org/10.1038/s41586-024-07107-7).

A one-row Julia generation smoke test is:

```bash
julia --project=julia/ToricBuilder -e '
  include("julia/ToricBuilder/example/scripts/decouple_bbcodes.jl")
  main(list=ab_list1[1:1], warmup=false, show_progress=false)

```

## Area And Locality Scaling

Run:

```bash
julia --project=julia/ToricBuilder \
  julia/ToricBuilder/example/scripts/plot_area_comparison.jl
```

The script combines both tables. For every completed row it defines the qubit
number per supercell as `q = 2 * area`. The time fit uses all 60 completed rows;
the locality fit uses the 59 rows with positive degree. The fitted exponents
are

```text
T proportional to q^1.86
deg(psi_1^-1) proportional to q^0.65
```

The Julia result-table field `Maximum_degree_phi_1` stores the same basis-change
matrix denoted by `psi_1^-1` in the paper's map convention. The plot therefore
uses the paper-facing label `deg(psi_1^-1)` without changing any numerical
values.

The reported wall-clock timings were measured on a Mac mini with an Apple M4
chip (10 CPU cores: 4 performance and 6 efficiency cores) and 32 GB RAM,
running macOS 26.5.1 and Julia 1.12.5.

## Transported CNOTs

`julia/ToricBuilder/results/transported_cnot_support.json` records all 40
ordered sector pairs for the six BB codes in the supplementary table. The
script reconstructs each toric form, computes

```text
Q = phi_1 * E * phi_1_inv
```

and reports the maximum Laurent-monomial count in a column of `Q`:

```bash
julia --project=julia/ToricBuilder \
  julia/ToricBuilder/example/scripts/transported_cnot_support.jl
```

The Julia test suite recomputes and compares all 40 values.
